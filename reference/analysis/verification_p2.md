# P2 核实记录：chunk_reports.md 与 storyboard.md 的冲突

本文只记录可复现的测量结果。每条结论注明依据和置信度；未验证的内容放在第 5 节。

数据来源：
- 逐帧差分：`reference/analysis/motion_diff.txt`（`帧号 差分值`，指第 n 帧与第 n-1 帧之间的差）。
- 计数器 OCR：`scripts/analysis/counter_ocr.py` 产出 `reference/analysis/counter_reference.tsv`（全部 4410 帧）。
- 取色：`scripts/analysis/sample_pixels.py`。
- 帧号标注的对照图：用 ffmpeg 生成，`drawtext=text='%{n}'` 写在 `select` 之前，因此图上的数字就是原片帧号。

## 2. 帧计数器

OCR 方法：从 crop(80×22 @ x=968, y=43) 截取 4 位数字，按 12 px 字宽切格。模板用帧 0–3699 训练（假设显示值 = f+1）；识别时在 ±2 px（x）、±1 px（y）范围内搜索偏移，用归一化相关打分。最低匹配分：计数段 0.763，倒带段 0.776。

| 说法 | 来源 | 核实结果 |
|---|---|---|
| 总帧数 “共 4418 帧”，计数器不可信 | chunk_reports L196 | **不成立**。目视确认是 `共 4410 帧`；0–3744 全部 3745 帧都识别为 f+1，0 处不符。 |
| f0 = 0000 | chunk_reports L10 | **不成立**。帧 0 显示 `0001`。 |
| 右上角是“装饰性递减数字 3743→3730…” | chunk_reports L363 | 实际就是倒带中的帧计数器（见下）。 |
| S13 倒数 3744→…→0001 | storyboard §S13 | **成立**，细节如下。 |
| S14 期间计数器隐藏 | storyboard §0 | **成立**，但隐藏从 4059 开始，早于 S14 的起点。 |

逐段行为（全局帧，`[from, to)`）：

| 区间 | 显示 | 依据 |
|---|---|---|
| [0, 3745) | f+1 | OCR，3745/3745 帧一致 |
| [3745, 3754) | 停在 3744 | OCR |
| [3754, 4019) | 单调递减，先慢后快再慢，形状接近 cubic in-out | OCR，逐帧值见 TSV |
| [4019, 4033) | 0001 | OCR |
| [4033, 4059) | 整条计数器（含文字）向左上方移出并缩小：墨迹 bbox 从 x 941–1193、y 51 移到 x 409–602、y 18，最大亮度从 234 降到 164；4059 消失。逐帧关键点见 `src/film/data/counterMove.ts` | col_profile（lum > 45）。OCR 在这一段无效，TSV 里 state=moving。（修正：之前写的“4047 起亮度 < 135”是 crop 固定位置造成的假象） |
| [4059, 4320) | 隐藏 | 亮度 ≤ 17 |
| [4320, 4410) | f+1 | OCR，90/90 帧一致（4410 显示为 `4410`） |

倒带段的逐帧值是唯一可信的标准，直接从 `counter_reference.tsv` 读取。解析式拟合 `floor(3743·(1−cubicInOut((f−3744)/284)))+1` 的最大误差是 4，只作参考。

采样值（frame=value）：3764=3739、3787=3693、3817=3491、3852=2921、3880=2097、3886=1869、3907=1154、3930=0612、3960=0204、3990=0036、4002=0012、4019=0001。

## 4. 背景

取色（帧 30）：四角 #14120e；中心区域 #1d1815。径向椭圆渐变，横向较宽。横向读数：x160 #17120f → x200 #191411 → x320 #1b1613 → x560 #1d1815；纵向读数：y20 #191411 → y100 #1b1613 → y240–360 #1d1815 → y520 #1a1512 → y700 #14120e。中心略高于画面中线（y≈300）。storyboard 的目测值 #1a1310 改为以上取色值。

## 5. 仍未确定的项

- 节拍相位：音频起音折叠（100 BPM）的峰值在第 ≈3.2 帧（次峰 2.2）。画面拍点：1441（mod 18 = 1）、1472…1562（mod 18 = 14）、2592（mod 18 = 0），彼此不一致。所以相位**没有唯一值**，`beats.ts` 里标为待定，每个场景要按实测的峰值帧对齐，不能直接套公式。
- storyboard 写的“节拍相位约在帧 2”和“2612/2630/2648…”需要逐场景复核。
- 帧 3885 的计数值（1908）匹配分偏低，可能有 ±1 的误差。
- 帧 710 在 y 72–73 处看到一条 #302b28 细线，可能是转场中的残影，未定。
- 音轨是纯音乐还是带人声：未核实（没有转写工具）。
- 3169、519、3025、3848 的瞬切内容还没有逐帧目视确认。
